# Titanic Survival Prediction — Machine Learning Model

## About This Project
This project is part of the Pluto Academy AI & ML Internship Program (Project 02).
I built, trained and evaluated multiple machine learning models to predict 
survival of Titanic passengers based on their features.

## Dataset
- Source: [Titanic Dataset — Kaggle](https://www.kaggle.com/c/titanic)
- Features: Passenger class, age, gender, fare, embarked, and more

## Tools Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Google Colab

## Project Structure
- `Titanic_ML_PlutoAcademy.ipynb` — Main notebook with full analysis
- `README.md` — Project overview

## What I Plan To Do
1. Load and preprocess the dataset
2. Perform feature engineering and selection
3. Train 3 different ML models
4. Compare and evaluate all models using proper metrics
5. Identify best model with confusion matrix and conclusion

## Models I Will Train
- Logistic Regression
- Random Forest Classifier
- K Nearest Neighbors (KNN)
